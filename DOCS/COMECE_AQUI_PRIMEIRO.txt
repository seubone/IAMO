================================================================================
PASSO 2: COLAR NO SUPABASE
================================================================================

1. Abra: https://app.supabase.com
2. Selecione seu projeto
3. Clique em "SQL Editor" (lado esquerdo)
4. Clique em "New Query" (botão no canto superior)
5. Cole o SQL (Ctrl+V)
6. Clique em "Run" (botão verde no canto superior direito)
7. Espere aparecer ✓ "Success"

Se vir qualquer erro tipo:
- "Table already exists" → OK! (significa que criou)
- "Column already exists" → OK! (significa que atualizou)

================================================================================
PASSO 3: COMPILAR E TESTAR
================================================================================

Abra o terminal e execute:

npm run build
npm run dev

Abra o navegador em:
http://localhost:3000
