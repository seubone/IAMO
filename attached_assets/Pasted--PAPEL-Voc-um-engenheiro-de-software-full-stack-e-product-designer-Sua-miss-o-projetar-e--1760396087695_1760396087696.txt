<--REQUISITOS_TÉCNICOS--> Frontend: React + Vite, TailwindCSS (design tokens), Zustand/Redux p/ estado, React Query p/ dados; ícones lucide-react.

Theming: modo claro/escuro com CSS variables. Base clara: fundo #FFFFFF, texto #0A0A0A. Base escura: fundo #0B0B0D, texto #F5F6F7.

Tokens: --brand:#FBC000, --brand-contrast:#050403, --muted, --surface, --border, --success, --warning, --error. Amarelo apenas como destaque/CTA.

Backend: Node.js + Express; WebSocket/EventSource p/ realtime; Zod p/ validação. DB: PostgreSQL + Prisma.

Tabelas:

ias (id, nome, status, tags[], criado_em, atualizado_em)

tickets (id, ia_id, atendimento_id, tipo_erro, severidade, mensagem, sugestao, origem, criado_em, status_ticket)

acoes (id, ia_id, usuario_id, acao, motivo, criado_em)

usuarios (id, nome, email, role, hash, preferencias_json)

Integração N8N: endpoint /webhooks/n8n/log (POST). Segurança: JWT, rate limit, auditoria. <--REQUISITOS_TÉCNICOS-->
